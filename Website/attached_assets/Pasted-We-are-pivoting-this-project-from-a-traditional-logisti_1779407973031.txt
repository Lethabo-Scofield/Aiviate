We are pivoting this project from a traditional logistics/fleet dashboard into an AI-native Autonomous Logistics Operations System.

The goal is NOT to build another CRUD logistics platform with many screens and options.

The goal is to build an intelligent operational system that can:

* understand logistics operations in real time
* predict operational failures
* autonomously coordinate logistics workflows
* optimize routes dynamically
* communicate automatically with customers and drivers
* reduce human coordination work
* eventually operate logistics companies semi-autonomously

CORE PRODUCT VISION

This system should function like an AI operations brain for logistics companies.

The system should:

* monitor live fleet telemetry
* understand operational state continuously
* detect anomalies
* predict delays and bottlenecks
* reroute automatically
* notify customers automatically
* schedule dynamically
* optimize operations continuously
* assist dispatchers with recommendations
* eventually perform autonomous operational actions

We are NOT building:

* generic fleet software
* basic dashboards
* bloated ERP-style logistics software
* feature-heavy admin panels

We ARE building:

* operational intelligence infrastructure
* logistics decision-making systems
* AI-driven operational automation
* autonomous logistics coordination

ARCHITECTURE DIRECTION

The platform should evolve into these layers:

1. DEVICE / TELEMETRY LAYER

* GPS tracking
* battery
* signal
* accelerometer
* driver behavior
* route execution
* live events
* edge telemetry ingestion
* future camera and sensor support

2. MOBILE EXECUTION LAYER
   Driver application used for:

* navigation
* deliveries
* proof of delivery
* live instructions
* AI assistance
* telemetry streaming
* dynamic rerouting
* communication workflows

3. OPERATIONS COMMAND CENTER
   The web dashboard should become:

* a real-time operational command center
* not a generic admin dashboard

The UI should focus on:

* operational risks
* bottlenecks
* AI recommendations
* delayed deliveries
* anomalies
* actions required now

NOT:

* unnecessary analytics
* excessive settings
* decorative metrics
* cluttered enterprise UI

4. AI OPERATIONAL INTELLIGENCE LAYER
   The intelligence layer becomes the core product.

Examples:

* ETA prediction
* delay prediction
* driver risk scoring
* route optimization
* anomaly detection
* congestion prediction
* warehouse bottleneck prediction
* operational recommendations
* autonomous dispatching

5. AUTONOMOUS WORKFLOW ENGINE
   The system should eventually:

* send emails automatically
* send WhatsApp/SMS automatically
* call customers automatically
* reschedule deliveries automatically
* reroute drivers automatically
* escalate operational risks automatically
* coordinate operations with minimal human intervention

The system should operate using:

* event-driven architecture
* AI agents
* operational rules
* predictive models
* telemetry intelligence

IMPORTANT PRODUCT PRINCIPLES

1. Minimize operational coordination cost
2. Focus on decisions, not dashboards
3. Surface only meaningful operational intelligence
4. Reduce human intervention over time
5. Build for autonomy gradually
6. Keep interfaces clean and operationally focused
7. Prioritize intelligence over feature count
8. Build around telemetry and operational data
9. Think like an air traffic control system, not an admin panel
10. Every UI component must answer:
    “What operational decision does this help make?”

Build an AI-native logistics operating system capable of:
