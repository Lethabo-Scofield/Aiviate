# Hardware Assumptions

Status: planned only.

Planned hardware assumptions:

- Driver-facing camera with configurable frame rate.
- GPS receiver or paired mobile GPS context.
- Network connectivity with offline buffering.
- Secure device identity material stored outside application logs.
- Firmware version reporting.
- Future motion or impact sensors may be added.
- Visible or audible driver warning channel.

These assumptions are not implemented in this repository.
